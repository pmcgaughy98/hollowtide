## Use one brief at a time

Open the [current Hollowtide Sprite Forge](https://opal.google/edit/1-WLZWZcCWFr8l5YTMOFUqBq-1Da2V-eY) for new Stage I fronts and same-form redraws. Use the [Hollowtide Evolution Forge](https://opal.google/edit/13O5Xm_9Go-u1cKn9TUCWAZhAXDe6OKbV) for Stage II/III fronts and their true same-form backs. Paste one form's brief into the relevant text input. For a new Stage I front, leave Previous Stage Sprite (optional) empty. For Stage II or III, attach only the immediately previous sprite from that same line; prefer its approved Forge original from `docs/HollowTide Sprites/Creatures/`. For a same-form redraw such as Rimefin, put `TASK: REDRAW` on the first line and attach that form's current front. For a back view, put `VIEW: BACK` on the first line and attach the exact form's approved front. For any front that needs the approved creature finish, put `docs/HollowTide Sprites/Creatures/Cinderhide.jfif` in the separate Style Anchor (optional) input. It controls pixel craft, never another species' anatomy or palette. Review each result before converting or importing it. The nine Ember fronts exist, while other lines still need generation.

The current live Forge workflow is documented in [Sprite Forge v6 prompt notes](opal-sprite-forge-prompt-v6.md): Nano Banana Pro, one creature, a 100-by-100 logical pixel grid, and an exact flat magenta (#FF00FF) background. Its three input links and text survived a page reload, but the first Vitrecrag generation hit Opal's daily quota before producing an image. Convert approved downloads with `python tools/convert_forge_sprite.py <in> <out.png> --compare <sheet.png>`, preserving the detected logical grid, then review the compare sheet before import. **Do not use `tools/opal-sprite-converter.html` for Forge art;** it shrinks to 64x64 and Preston rejected the results.

The current Forge prompt supplies the common rules: pixel grid, solid magenta background, one centered creature, crisp angular pixels, strong silhouette, a purposeful palette, no text, shadow, or extra forms. It asks for Cinderhide-level material clusters and shading, and later stages change pose, proportions, and silhouette while preserving a few identity anchors. Aim for mature grounded folklore; avoid cute, round, chibi, or toy-like proportions. The briefs below specify name, essence, anatomy, silhouette, temperament, pose/facing, palette, and avoid-list.
