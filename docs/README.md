# Where things are

Sorted 2026-09-30. Start with `AI_COLLABORATION.md` for the latest handoffs between Claude and Codex.

| Folder | What is in it |
|---|---|
| `team/` | How the assistants work: the role charter, Claude's work plan, setup notes, briefs for Codex |
| `world/` | The world bible, the region atlas, the first route and the people in it |
| `creatures/` | The roster, each creature line, sprite boards, back-view work. `source-art/` holds the original creature images |
| `battle/` | Battle rules, moves, attack animation, the camera. `balance/` holds the simulator report |
| `audio/` | Music prompts and sound design for each creature |
| `forges/` | Opal Forge prompts and records. `gemini-skills/` holds the Forges converted for Gemini (Opal closes 2026-11-17) |
| `art/` | Art direction, palettes, rigs. `review/` holds review images |
| `research/` | Research tasks sent to Gemini and Grok, and what was adopted from each |
| `Gemini DeepResearch(Hollowtide)/` | The research documents themselves (Preston drops new ones here) |
| `HollowTide Sprites/` | A few attack sheets copied from OneDrive. The full set lives in OneDrive `Documents/HollowTide Sprites` |
| `archive/` | Old material kept for reference, including a large sound pack that is not in Git |
| `Codex/` | Codex's working area (not in Git) |

Godot does not import anything in this folder (`.gdignore`), so images and documents here never slow the editor or
end up in the game.

The design authority is `THE_CONCEPT.md` in the project root, not anything in here.
