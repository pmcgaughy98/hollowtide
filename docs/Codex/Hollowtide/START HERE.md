## Where to save the next file

- New raw creature or effect art: save under the matching `docs/HollowTide Sprites` source folder; preserve original output. Add its status to the sprite production board.
- Gemini research DOCX: put a copy in `Research Originals` and note the result in the project adoption note.
- Godot-ready art: add to `assets/sprites` only after sprite review, transparency cleanup, and correct resource linking.
