## Claims from the Three-Agent report to treat as hypotheses

The report contains useful division-of-labor ideas, but several technical prescriptions are too absolute or are unverified in this project. Do not automatically enforce a universal 100×100 grid (Vitrecrag has approved 128×128 art), aggressive magenta erosion, global K-means palette locking, Sobel-derived normal maps, mandatory linear stats, forced static typing everywhere, automatic UID conflict resolution with `--ours`, cache deletion, or disabled leak checks. Each could damage approved art, hide a bug, or pre-decide game feel. Prototype and measure a specific need first; retain original files. Use official engine documentation for API claims.

## Handoff rule

Before editing a shared game file, check current disk contents and the latest AI collaboration handoff. One agent owns each active file at a time. Record what is **proposed**, **implemented**, **visually approved**, and **played/verified** separately. Pass exact paths and remaining decisions to the next agent. Preston can assign any specific task to any agent regardless of this default chart.
